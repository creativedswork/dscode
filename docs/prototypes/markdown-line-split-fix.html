Markdown Line-Split Fix

Prototype
Current — split('\n') + per-line Markdown
Fixed — single Markdown + DOM post-process

What's happening

The left panel shows the current broken behavior: content.split('\n') wraps each line in its own <Markdown> component. Multi-line constructs like fenced code blocks, lists, and tables are destroyed because each line is parsed in isolation — adjacent lines can't "see" each other.

The right panel shows the fix: render the entire content as one Markdown pass, then post-process the rendered HTML to wrap each line in a <span data-collider="text-line">. This preserves Markdown integrity while still providing line-level DOM targets for TransitionCanvas.
