Before → After

✗ Before

  • Progress text only visible in collapsed Thinking block
  • ToolCard body completely empty during execution
  • Header shows static ◌ with no progress indication
  • User has to manually expand Thinking to see status
  • Progress data from notifications/progress unused in UI

✓ After (this prototype)

  • Execution card inside ToolCard body with live thinking log
  • Progress bar with percentage + message + elapsed time
  • Header spinner + mini bar when collapsed
  • All execution context in one place — single click to expand
  • Graceful fallback: "Waiting..." state when no progress yet
