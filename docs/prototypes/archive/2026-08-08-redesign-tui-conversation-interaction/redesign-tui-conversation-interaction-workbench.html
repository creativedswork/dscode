TUI conversation redesign

Chat 保持安静，Activity 进入可聚焦的 Inspector

WebUI 与 TUI 共享同一份 Conversation/Execution 数据和 disclosure 语义；终端不再依靠三个全局快捷键猜测目标，而是用单一入口切换到具备稳定焦点、局部键盘路由和可滚动详情的检查模式。

一个入口，一个焦点Ctrl+E 打开 Activity Inspector；Tab / Shift+Tab 切换，Enter 激活当前项。
输入优先Chat 模式下 Editor 拥有常规按键，移除全局 Ctrl+R/O/N 劫持。
摘要不是删除对话只展示 Tool 摘要；Inspector 使用 viewport 浏览完整结果，不再二次截断为 120 字符。
审批绑定 ownerPermission 以所属 Agent/Tool Card 的聚焦态出现，并强制接管输入直到解决。

共享数据，分离渲染。TUI 应直接消费 canonical UIMessage[] 和 reducer，不再维护第二套 mutable ContentBlock、toolEntries 与 replay 分支。
