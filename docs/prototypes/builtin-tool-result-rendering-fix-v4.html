ToolCard Spacing v4 — Root Cause Fix

Why built-in tools still show blank space after v3 changes. Two root causes identified and fixed.

Root Cause Analysis

Why MCP tools look fine but built-in tools don't:
  • Cause 1 — Missing background: .mcp-raw-block has background: var(--color-bg) but .tool-card-body-inner does NOT. The 2px container padding is invisible on MCP (same color as <pre> background) but visible on built-in tools (--color-surface vs --color-bg contrast).
  • Cause 2 — Inline styles on <pre>: The Markdown component renders <pre> with style={{ border, borderRadius, backgroundColor }}. Inline styles (specificity 1,0,0,0) cannot be overridden by CSS selectors like .tool-card-body-inner pre (specificity 0,2,0). So border: none and border-radius: 4px from our CSS never take effect — the <pre> keeps its full border and 8px radius.
Fix: (1) Add background: var(--color-bg) to .tool-card-body-inner. (2) Move Markdown <pre> inline styles to a CSS class so scoped overrides work.
