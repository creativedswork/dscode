## Prototype Files

- `docs/prototypes/web-ui-editorial-workshop-scale-revision.html` — Side-by-side comparison of current (v1) vs proposed (v2) typographic scale. Demonstrates:
  - **Scale bump**: All UI chrome +1-2px (section labels 10→11, panel titles 13→15, skill names 12→13, descriptions 10→11, tags 9→10, buttons 10→11/11→12, phase labels 10→11)
  - **Resizable detail panel**: Right column detail panel has a drag handle (min 200px, max 420px). Left column (current) is fixed-width for comparison.
  - **Marketplace button disabled**: "Browse Marketplace" button is disabled with a "Coming soon" tooltip on hover.
  - **State switching**: Bottom-right controls toggle between Skills, Sessions, Settings, and Chat views.
  - **Scale legends**: Bottom bars show exact before/after px values for each element type.
  - **Confirmed design decisions**: Typographic scale shifts documented in design.md D1 table, resizable panel parameters (default 320, min 240, max 480), disabled marketplace with tooltip copy.
